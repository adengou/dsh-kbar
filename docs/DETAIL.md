# KBar 命令面板

KBar 在 DSH 界面之上加一个命令面板：按一次快捷键，输入几个字，就能跳到任意会话，或执行常用动作。

## 使用

- 默认快捷键：**Windows/Linux `Ctrl+Shift+P`**，**macOS `Cmd+Shift+P`**。
- 输入即过滤：会话按标题和工作目录匹配，动作按名称匹配。
- `↑` / `↓` 选择，`Enter` 执行，`Esc` 关闭；右上角 `×` 也能关闭，点击空白处也会关闭。
- 面板顶部有一条拖动栏：按住可移动，双击回到居中位置，位置会记住。
- 侧边栏底部有「打开命令面板」入口；侧边栏收起时显示为图标。
- 打开时输入框自动聚焦，关闭后焦点回到原来的控件。

## 能做什么

| 类型 | 内容 |
| --- | --- |
| 会话 | 当前会话目录里列出的所有会话（标题、工作目录），按最近更新排序，选中即切换 |
| 命令 | DSH 里所有已注册的快捷键命令（新建会话、设置、侧栏、终端、文件等），选中即执行 |
| 斜杠命令 | 当前会话的命令目录（`/compact` 等），选中即执行 |
| 技能 | 宿主目录接口按当前工作区返回的技能（名称、描述），选中把 `/技能名` 复制到剪贴板（粘到输入框即可调用） |
| 模型 | 当前会话可用的模型（按厂商分组），选中即切换，并沿用该模型的默认推理强度 |
| 插件 | 宿主目录接口 `/api/kbar/catalog` 返回的 bundle（名称、版本、描述），选中打开对应的插件详情页；面板激活后自动预热 |
| 动作 | 新建会话；打开插件页 |

## 为什么不占 Ctrl+K

`Ctrl+K` 在 DSH 里已经是官方的「搜索会话」快捷键（`session.search`）。两个功能同时抢一个组合键会导致插件注册冲突，所以 KBar 默认用 `Ctrl+Shift+P`。

你可以在 **设置 → 快捷键** 里把 KBar 改到自己喜欢的组合；如果改成 `Ctrl+K`，会与官方会话搜索冲突，请先把官方那个改走。

## 已知限制

- 快捷键命令只包含带快捷键定义的应用命令；斜杠命令仍读客户端命令目录，需要会话处于打开状态。
- Linux 浏览器下没有默认快捷键（DSH 的 Web 快捷键策略只放行特定组合），请在 **设置 → 快捷键** 手动绑定 `Ctrl+Shift+P` 或其它组合。
- 需要参数的斜杠命令不会直接执行，选中后把 `/name ` 复制到剪贴板，由你补参数再发送。
- 斜杠命令仍读客户端命令目录，web 端可能为空；技能与插件由宿主目录接口提供，技能按当前工作区加载。
- 技能只提供“复制 /技能名”，不直接替用户发送，避免误触模型调用。
- 模型列表只在存在当前会话时加载；没有会话时该分组为空。
- 插件列表来自宿主目录接口，首次加载需要一两秒；选中后打开插件详情页，不在面板内直接启停。
- 部分命令依赖当前焦点所在的控件，通过面板执行时可能提示“不可用”（例如需要选中某个侧栏标签的命令）。
- 会话列表来自客户端已加载的目录快照；尚未被加载的历史会话不会出现。
- 面板是覆盖层，关闭后不会改变当前页面；执行动作会先关闭面板再执行。
- 不联网、不收集数据。

## 配置

当前版本没有可配置项。快捷键沿用 DSH 的快捷键服务，改键后保存在本机。
